Abilities

Each time this model destroys an enemy CHARACTER model, you gain 1CP

In your Command phase, select one enemy unit within 12" of this model. That unit must take a Battle-shock test

While an enemy unit is within 12" of this model, if that unit is Battle-shocked: - Each time a model in that unit makes an attack, subtract 1 from the Hit roll. - Each time a friendly TYRANIDS model makes an attack that targets that unit, add 1 to the Wound roll.

During deployment, if every model in a unit has this ability, it can be set up anywhere on the battlefield that is more than 8" horizontally from your opponent’s deployment zone and all enemy units.
